| 文档 | 定位 | 何时看 |
| --- | --- | --- |
| [`plan.md`](plan.md) | **战略地图**：四阶段（入门 → 进阶 → 高阶 → 专家）全景、每阶段目标 / 项目 / 通关标准 | 把握方向、判断"学到哪、下一步学什么" |
